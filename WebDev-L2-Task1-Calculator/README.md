# Calculator – OIBSIP Level 2 Task 1

A fully functional browser-based calculator developed as part of my OASIS Infobyte internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Operator chaining
- Proper operator precedence
- Clear functionality
- Delete functionality
- Division-by-zero handling
- Interactive button-based interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in a web browser.
3. Use the calculator buttons to perform calculations.
