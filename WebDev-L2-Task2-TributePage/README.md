#  Sunita Williams — Tribute Page

A responsive and visually engaging tribute webpage dedicated to **Sunita Williams**, an accomplished astronaut, naval aviator, and NASA space explorer.

This project was created as part of a web development task to practice **HTML5, CSS3, responsive design, page structure, typography, and visual presentation**.

---

##  Project Overview

The Sunita Williams Tribute Page presents an overview of her life, career, achievements, and contribution to space exploration.

The webpage is designed to provide information in a clean and organized manner while using images, styled sections, cards, typography, and a responsive layout to create an engaging user experience.

The page includes:

- A hero section introducing Sunita Williams
- A prominent image
- Biography and early-life information
- Military and astronaut career information
- A chronological timeline
- Major achievements displayed as styled cards
- A notable quote
- Information highlighting her connection with India
- Responsive design for different screen sizes

---

##  Objective

The objective of this project was to design and develop a visually appealing tribute page dedicated to a historical figure, scientist, artist, astronaut, or public figure.

The project focuses on demonstrating fundamental frontend development skills using:

- HTML5
- CSS3
- Responsive Web Design
- Flexbox
- Typography
- Images and visual content
- Semantic webpage structure

CSS3 was used to design and style the webpage.

The project uses CSS for:

- Colors
- Typography
- Spacing
- Layout
- Flexbox
- Borders and border-radius
- Image styling
- Responsive design
- Section styling

JavaScript was not required for the core functionality of this project. The webpage is primarily a static tribute page created using HTML and CSS.
